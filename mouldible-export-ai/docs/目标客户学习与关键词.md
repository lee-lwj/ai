### 1.4 数据质量问题 Data Quality Issues

1. **海外同行占比高（现视为机会）:** 域名含 `formenbau` / `mould` / `mold` / `spritzguss` / `matrijzen` 的大量是海外模具/注塑厂；按 Rocky 策略，作 **溢出外发线索** 保留，勿当垃圾剔除。

4. **Freemail 少量但仍有:** ~812，适合人工跟进弱；企业开发应过滤 `is_freemail=True`。
5. **公司名猜测粗糙:** `company_guess` 仅去掉 TLD，子域/复合名需人工校对。
6. **站点可达性:** 部分欧洲站对爬虫返回 5xx/超时；学习时用了 WebFetch + 公开搜索互证，报告中已标注证据来源。

从非 freemail 域名按 `.com / .de / .ch / .co.uk / .nl / .com.au / .net / .it` 分层抽样，对能打开的页面阅读分类（**不编造页面内容**）。完整记录见 `sample_site_classifications.json`。

### 2.1 ICP 模式（白话）/ ICP Pattern in Plain Language

现有名单 **不是「纯买家清单」**，而是一张 **塑料/模具产业链通讯录**，大致四层：

1. **理想买家 / Ideal buyers（偏少但最值钱）**  
   - 产品公司、OEM：需要外壳、结构件、家电/汽配/IT 配件的塑料件，自身不做模具。  
   - 例（抽样）：`parkmfg.com`（线束/机电组件，可能买塑料壳体）、`digisens.ch`（传感器/称重设备 OEM）。

2. **高价值影响者 / Specifiers（强烈建议优先开发）**  
   - 工业设计公司、产品开发工作室、DFM 顾问：他们决定材料与工艺，并推荐/指定模具厂。  
   - 例：`crescentinnovation.com`、`morosinidesign.com.au`、`flynn-product-design.com`、`seymourpowell.com`、`productdesignco.com`（电子产品设计，常需塑料外壳）。

3. **渠道 / Sourcing partners**  
   - 帮助欧美客户做全球 sourcing、开模量产的中介。  
   - 例：`smart-sourcing.com`（明确做 metals/plastics 离岸制造）。

4. **同业 / Competitors & peers（名单里很多，需负面过滤）**  
   - 模具厂 Formenbau、注塑厂、带自有模具车间的 moulder、模具标准件商。  
   - 例：`admo.ch`、`gebrema.nl`、`promolding.nl`、`stutcheng.com.au`、`modelsllc.net`、`catalystpdg.com`、`reichert-formenbau.de`、`dms-diemould.co.uk`、`jokey.com`（大型包装注塑+自有工装）、`ruetschi.com`（医疗注塑+自有模具）。

5. **生态但非买家:** 注塑机维修、粉碎机（ZERMA）、过程控制（FACTS）、金属钣金外壳厂等。

6. **无关 / 失效:** 五金批发、纸艺工作室、停放域名等。

**与 Mouldible 的关系:**  
Mouldible 卖的是「开模具 + 快速原型 + 工装 + 可配合注塑」。目标客户包括两类：  
1）**终端买家路径：** 设计工作室 + OEM 产品公司 + sourcing 公司；  
2）**同行外发路径（Rocky 确认）：** 中国以外的模具厂 / 注塑厂，在产能满载时把模具或注塑单外发到中国（广州 Mouldible）。  
`.de` Formenbau 等海外同行 **应保留并主动开发**，话术侧重产能互补、交期支持、钢模性价比，而非「抢客户」。仅把中国大陆同业、纯标准件商、无关行业作负向过滤。

## 5. 规模化发现邮件的建议 Next Steps

## 5. 多渠道职位与联系人挖掘（补充）

Rocky 要求：职位与邮箱必须 **多方式** 获取，不能只停在一串邮箱；挖掘/富化须覆盖 **六大渠道**（官网、社媒、多引擎搜索、地图、展会登记名录、使馆商务信息），而非仅网站 + LinkedIn/Facebook/Xing。

1. **官网：** Contact / Team / Imprint → 抓公开邮箱与人名职位。  
2. **LinkedIn：** 公司页 + Purchasing / Sourcing / Tooling / Design / Managing Director 等员工。  
3. **Facebook（及 IG/X）：** 主页 About 邮箱、电话、外链；消费品牌类尤其有用。  
4. **Xing：** 德语区 Formenbau / 采购决策人补充。  
5. **多引擎搜索：** Google / Bing（及 DuckDuckGo、区域引擎）— 公司名+contact/email/phone、`site:domain`、品类+城市；交叉摘要中的电话与邮箱。详见 §3.7。  
6. **地图：** Google Maps / Bing Maps / Apple Maps / OSM — 工厂/办公地址、列表电话、周边同行扩池。详见 §3.7。  
7. **展会登记与参展商/观众公开名单：** K Show、Fakuma、NPE、Chinaplas 等塑料/模具展官方目录与合法公开登记线索。详见 §3.7。  
8. **大使馆 / 领事馆商务信息：** 经商处、贸促页、企业名录、伙伴/招标公开名单。详见 §3.7。  
9. **合并：** 同一联系人多来源合并；邮箱验证后再进主表。  
10. **海外同行：** 优先挖老板 / 销售负责人（溢出外发决策快）；ICP 仍为 OEM/设计/寻源 + 非中国同行外发。

详细步骤与表字段见 `外贸AI化项目方案.md` §3A（v1.3）。
